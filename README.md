One line: the excuse a gamer texts the boss to skip work on GTA 6 launch week — the plumber can only come today, so someone has to wait in, and the gamer will be online later.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` (Python 3.13, standard library only, no network, no randomness) writes the entry line to `/output/entry.txt` — 96 characters, 20 words, inside the gate's 1–140 characters and the brief's 20-word limit — so both grader runs write identical bytes.
